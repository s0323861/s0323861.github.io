# 幹事くんをPHPとBootstrap 5でリニューアルしました

以前から公開していた出欠確認Webサービス「幹事くん」を、PHPとBootstrap 5を使って作り直しました。

幹事くんは、飲み会やイベントなどの出欠確認を簡単に行うためのWebサービスです。参加者は名前と出欠を入力するだけで回答でき、幹事は参加状況を一覧で確認できます。

今回のリニューアルでは、古いコードを見直し、画面のデザインや使いやすさを改善しました。Bootstrap 5を使うことで、スマートフォンでも見やすいレイアウトになるようにしています。

## 今回改善したこと

主な改善点は次の通りです。

- PHPでコードを書き直した
- Bootstrap 5を使ってデザインを整えた
- スマートフォンでも見やすい画面にした
- 入力フォームや一覧画面を使いやすくした
- 今後の機能追加がしやすい構成にした

## 今後追加したい機能

今後は、次のような機能も追加していきたいと考えています。

- 英語表示への対応
- 参加者へのコメント機能
- イベントごとの締切設定
- 幹事向けの管理機能の強化
- デザインのさらなる改善
