# 予約くん Version 1 が完成しました

登録不要で使える軽量予約システム「予約くん」の Version 1 が完成しました。

予約くんは、個人レッスンや面談、イベント受付などの予約を簡単に受け付けるためのWebサービスです。

管理者は予約ページを作成してURLを共有するだけで予約受付を開始でき、利用者は名前を入力するだけで簡単に予約を行うことができます。

## 開発した理由

最近は手軽に予約を受け付けられるサービスも増えていますが、

* 会員登録が必要
* 月額料金がかかる
* 機能が多すぎて使い方が難しい

と感じることも少なくありません。

そこで、

「URLを発行するだけですぐ使える予約システム」

を目指して開発を始めました。

できるだけシンプルで、誰でもすぐに使えることを重視しています。

## Version 1 で実装した機能

今回の Version 1 では、次のような機能を実装しました。

* 登録不要ですぐ利用開始できる
* URLを共有するだけで予約受付を開始できる
* スマートフォンに対応したレスポンシブデザイン
* 日本語と英語の表示に対応
* 予約人数の制限設定
* 予約枠の追加・削除
* 利用者による自己キャンセル機能
* 管理者による予約キャンセル機能
* メールアドレス入力機能（任意）

特に自己キャンセル機能と管理者キャンセル機能は、実際に運用する際に必要になることが多いため、Version 1 の段階で実装することにしました。

## 使用技術

今回の開発では主に次の技術を利用しました。

* PHP 8
* Bootstrap 5
* JavaScript
* JSONによるデータ保存

データベースを利用しない構成にしたことで、比較的簡単に設置できるようになっています。

## 今後追加したい機能

今後は、次のような機能も追加していきたいと考えています。

* メール通知機能
* Google カレンダー連携
* CSV エクスポート
* LINE 通知機能
* ダークモード対応
* 多言語対応の拡充

少しずつ機能を追加しながら、実際に使いやすい予約システムに育てていきたいと思います。

## おわりに

個人開発の小さなプロジェクトですが、実際に使えるものを作るという経験はとても勉強になります。

今後も改善を重ねながら、より使いやすいサービスにしていく予定です。

もし興味がありましたら、ぜひ一度触ってみていただけるとうれしいです。
